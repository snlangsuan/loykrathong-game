# ลอยกระทงทั่วไทย

เกมเดินเที่ยวงานลอยกระทงคืนวันเพ็ญ เลือกสถานที่จากแผนที่ประเทศไทย ซื้อกระทงหรือโคม จุดธูปเทียน อธิษฐาน แล้วลอยกระทงหรือปล่อยโคม
คำอธิษฐานของทุกคนลอยอยู่บนกระทงและโคมในเกมเป็นบอลลูนข้อความ

วาดด้วย WebGPU แบบเดียวกับโปรเจกต์ Endless (`js/engine.js` คัดลอกมาจาก `endless-driver/engine/engine.js`) ทุกอย่างบนจอวาดด้วยโค้ด ไม่มีไฟล์ภาพหรือโมเดล ไม่มีขั้นตอน build

## วิธีเปิด

```
bun run serve      # เล่นเฉยๆ
bun run dev        # ตอนพัฒนา: hot reload
```

`bun run dev`: แก้ CSS แล้วหน้าเปลี่ยนทันทีโดยไม่โหลดใหม่ · แก้ JS/HTML แล้วหน้าโหลดใหม่เอง โดยเกมกลับมายืนที่เดิม (ข้ามหน้าเข้างาน) และแผนที่คงตำแหน่งกับระดับซูมเดิม

แล้วเปิด http://localhost:8080 ต้องใช้เบราว์เซอร์ที่รองรับ WebGPU (Chrome หรือ Edge รุ่นปัจจุบัน) และต้องเปิดผ่านเซิร์ฟเวอร์ เปิดแบบ `file://` ไม่ได้
วางบน GitHub Pages ได้ทันที (เผยแพร่จาก root)

## สไตล์ภาพ

ค่าเริ่มต้นเป็นภาพแนวเกมสไตไลซ์: กลางคืนที่สว่างพอเห็นฉาก ฟ้าน้ำเงินม่วง สีอิ่ม พื้นหญ้าเรียบสะอาด หมอกฟ้าตามระยะ เมฆเป็นก้อนขอบแสงจันทร์
ปรับได้ใน `js/game.js`: ค่า `AT` (แสงและสีฟ้า), `grade` (การเกรดสีขั้นสุดท้าย), `leafTint` (สีใบไม้) และส่วนที่ขึ้นต้นด้วย `TOON` ใน shader
`js/engine.js` เพิ่มช่อง `grade` และ `bloom` จากของเดิมใน Endless
คนในงานเป็นตัวบล็อกมีข้อต่อ (`vsBlock` / `fsBlock` และ `putPerson()` ใน `js/game.js`): ต้นแขน แขนท่อนล่าง มือ ต้นขา หน้าแข้ง เท้า งอศอกและเข่าได้ หน้าวาดแบบพิกเซล ผมเป็นบล็อก แสงสองโทนและแสงขอบตัว ผู้หญิงบางคนห่มสไบนุ่งผ้าซิ่น

## โครงสร้างไฟล์

```
index.html, js/map.js, css/map.css   หน้าแผนที่: ลากเลื่อน ซูม (ล้อเมาส์ สองนิ้ว ปุ่ม + −) หมุดสถานที่ เริ่มที่ตำแหน่งผู้ใช้ (ถ้าอนุญาต) หรือกรุงเทพฯ
play.html, js/game.js, css/play.css  หน้าเกม: play.html?loc=<id>  (?q=low ภาพแบบเบา · ?look=real ภาพแบบสมจริงเดิม · ?debug แสดง fps)
js/engine.js                         engine จาก Endless
js/places.js                         ข้อมูลสถานที่
js/wishes.js                         ดึงและส่งคำอธิษฐาน (Firebase หรือข้อความตัวอย่าง)

js/loader.js, css/ui.css             หน้า loading และสไตล์ที่ใช้ร่วมกัน
firebase/database.rules.json         กฎของ Realtime Database
```

## วิธีเล่น

W A S D เดิน · Shift เดินเร็ว · เมาส์มองรอบ · E ซื้อ / จุดธูปเทียน / อธิษฐาน · M เสียง (บนมือถือ: ลากฝั่งซ้ายเดิน ฝั่งขวามอง ปุ่ม "ใช้")

1. มองที่กระทงหรือโคมบนโต๊ะร้านแล้วกด E เพื่อซื้อ
2. กระทง: เดินไปสุดท่าน้ำ · โคม: เดินไปที่ลานโคม (ตรงไหนก็ได้ในลาน)
3. กด E จุดธูปเทียน แล้วกด E อธิษฐาน พิมพ์คำอธิษฐาน กดตกลง (ไม่พิมพ์ก็ได้ = อธิษฐานในใจ ไม่ส่งขึ้นระบบ)
4. กระทงจะลอยออกไป หรือโคมจะพองลมแล้วลอยขึ้นฟ้า กล้องจะมองตามสักพัก

## คำอธิษฐานและ Firebase

ตอนนี้ใช้ Firebase Realtime Database ผ่าน REST (ไม่ต้องโหลด SDK) ถ้ายังไม่ตั้งค่า หรือดึงไม่สำเร็จ หรือยังไม่มีข้อความ เกมจะสุ่มคำอธิษฐานตัวอย่างมาแสดงแทน

1. สร้างโปรเจกต์ที่ https://console.firebase.google.com แล้วสร้าง Realtime Database
2. ใส่ที่อยู่ฐานข้อมูลใน `js/firebase-config.js` ช่อง `databaseURL`
3. ตั้งกฎจาก `firebase/database.rules.json` (เพิ่มสถานที่ใหม่เมื่อไหร่ ต้องเพิ่ม id ในกฎช่อง `place` ด้วย) (อ่านได้ทุกคน เขียนได้เฉพาะข้อความใหม่ ข้อความยาว 1–120 ตัวอักษร ห้ามแก้หรือลบ)

ข้อมูลที่เก็บ: `wishes/<push id> = { text, place, kind: 'krathong' | 'lantern', t }`
ตัวนับกระทงและโคม: `stats/krathong`, `stats/lantern` เพิ่มทีละ 1 ทุกครั้งที่ลอยหรือปล่อย (กฎยอมให้เพิ่มทีละ 1 เท่านั้น ลดไม่ได้)
ถ้าไม่ได้ตั้งค่าหรือดึงไม่ได้ เกมจะแสดงตัวเลขจำลองที่คำนวณจากเวลา (`SIM_BASE`, `SIM_RATE` ใน `js/wishes.js`) บวกกับที่ผู้เล่นลอยเอง เลขเพิ่มตามเวลาจริง และบนเครื่องเดิมจะไม่ลดลงเด็ดขาด
ส่งไม่สำเร็จจะเก็บไว้ในเบราว์เซอร์แล้วลองส่งใหม่ครั้งหน้า และระหว่างเล่นเกมจะดึงข้อความใหม่ทุก 45 วินาที

ข้อควรรู้: กฎแบบนี้ยังไม่มีการยืนยันตัวตนหรือจำกัดจำนวนการส่ง และไม่มีการกรองคำไม่สุภาพ ถ้าเปิดให้คนทั่วไปเล่น ควรเพิ่ม Firebase App Check หรือย้ายไปใช้ API ของตัวเอง
จะเปลี่ยน backend ให้แก้แค่ `BACKEND` ใน `js/wishes.js` (`list(limit)` และ `add(wish)`)
